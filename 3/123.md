# 서울시 월별 기온 시계열 분석 리포트

## 1. 분석 주제
서울시 월별 기온 데이터를 활용해 **계절 패턴, 여름 기온 상승 추세, 
일교차 변화**를 확인하고, 시계열 분해로 장기 추세를 검증한다.

## 2. 분석 질문
- **Q1.** 서울의 기온은 월별로 어떤 계절 패턴을 보이는가? (그래프로 확인)
- **Q2.** 여름철 기온은 장기적으로 상승하고 있는가? (추가 해석 필요)
- **Q3.** 일교차(최고-최저)는 시간에 따라 변하고 있는가? (추가 해석 필요)

---

## 3. 데이터 출처 및 재현성

- **출처**: 기상청 기상자료개방포털 (data.kma.go.kr)

- **라이선스**: 기상청 공공데이터

## 4. 데이터 정제

- **결측치**: 전체 136개 포인트 확인 결과 결측치 **없음**.
- **이상치**: 각 월의 물리적으로 가능한 기온 범위를 벗어난 값 **없음** 
  (예: 8월 음수, 1월 30°C 등). 계절 패턴과 일치하여 별도 제거 없이 전량 사용.
- **처리 기준**: 물리적으로 타당한 기온 범위 내 값으로 판단하여 유지.

---

## 5. 적용한 시계열 분석 기법 (2가지)

1. **선형 회귀(추세선)**  
   여름 기온·일교차의 장기 변화율(°C/년)을 **정량화**하기 위해 적용.  
   → Q2, Q3에서 기울기 계산에 사용.
2. **시계열 분해 (seasonal_decompose, 가법 모델)**  
   원본 데이터를 **추세/계절성/잔차**로 분리해 계절성을 제거한 뒤 
   순수한 장기 추세를 확인하기 위해 적용. → 보너스 분석.

---

## 6. 분석 결과: 관찰(근거) vs 해석(가설)

### Q1. 월별 계절 패턴
- **관찰(근거)**: 1월 평균 약 -2°C에서 8월 약 27°C까지, 월별로 규칙적인 상승-하강 반복.
- **해석(가설)**: 서울은 뚜렷한 사계절 특성을 가지며, 여름-겨울 기온차가 약 29°C에 달한다.

### Q2. 여름 기온 상승 추세
- **관찰(근거)**: 여름철 기온 회귀선 기울기 **+0.119°C/년**, 17년간 약 **+1.91°C** 상승.
- **해석(가설)**: 지구온난화/도시 열섬 효과로 여름이 점점 더워지는 경향으로 추정 (인과관계는 추가 검증 필요).

### Q3. 일교차 변화
- **관찰(근거)**: 일교차(최고-최저) 회귀선 기울기 **+0.054°C/년** (약한 상승).
- **해석(가설)**: 일교차는 소폭 증가 경향이나, 기울기가 작아 통계적 유의성은 제한적일 수 있다.

### 보너스. 시계열 분해 (Trend / Seasonal / Resid)
- **관찰(근거)**:
  - Trend 성분이 약 13°C → 15°C로 우상향.
  - Seasonal 성분이 매년 동일한 톱니 패턴(±10°C) 반복.
  - Resid(잔차)는 0 주변에 분포.
- **해석(가설)**:
  - 계절성을 제거해도 남는 **장기 상승 추세** 존재 → Q2 결과를 뒷받침.
  - 잔차가 0 근처 분포 → 가법 모델(additive)이 데이터를 비교적 잘 설명.

## 10. 결론 및 한계

### 결론
- 서울 기온은 강한 계절성을 보이며, 여름철 기온과 일교차가 **완만하게 상승**하는 경향.
- 시계열 분해로 계절성 제거 후에도 장기 상승 추세가 확인됨.

### 한계 및 주의사항
- 9~12월 미포함으로   **완전한 연주기 분석에 제약**.
- 추세 상승의 원인(온난화 vs 도시화)은 본 분석만으로 **단정 불가**.
- 17년(회귀 기준)은 기후 추세로는 짧아 통계적 유의성 검증이 추가로 필요.
